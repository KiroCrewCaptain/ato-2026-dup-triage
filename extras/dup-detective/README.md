# Dup Detective (earlier example app)

The first app built for this workshop: it finds likely duplicate issues and explains each
match. Today's labs build **Backlog Factory** instead (see `../../checkpoints/`). Dup
Detective stays here as a small, finished example to read.

- `lab-1/`, `lab-2/`, `lab-3/`: the `dup-triage` app after each of its three labs.
- `remix/skills/`: two extra skills (missing-info nudger, good-first-issue scout).
- `answer-key.md`: its duplicate groups and near-misses (for the first 45 issues).

The READMEs inside still say `checkpoints/lab-N`; read that as `extras/dup-detective/lab-N`.
Install one the same way: `kirocrew app install "$PWD/extras/dup-detective/lab-3"`, then
trust and enable **Dup Detective** in Library. Its posting step is for a fork you own; do
not use it on the shared workshop repo.
